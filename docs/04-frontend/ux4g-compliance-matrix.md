## 1. Governance & Verification Protocol

This document is the authoritative UX4G compliance and enforcement register for the AIRE platform frontend.

In accordance with `AGENTS.md` §2 and §12:

- Status claims must be supported by verifiable code and automated test execution.
- No requirement is marked `PASS` merely on the basis of descriptive documentation.
- The enforcement suite runs both unit/isolation tests (`vitest`) and real headless browser tests (`playwright`) across 7 viewports (320px to 1440px).

### Status Taxonomy

- **`PASS`**: Implemented in code, verified with passing automated test suite or real-browser check.
- **`PARTIAL`**: Partially implemented or subject to external dependencies (e.g., national production credentials).
- **`NOT APPLICABLE`**: Functionality outside approved statutory boundaries with documented justification.
- **`FAIL`**: Fails defined acceptance criteria or exhibits regressions.

## 3. Automated Enforcement Commands

To execute the automated UX4G regression suite locally and in CI:

```bash
# 1. Run client unit and component tests (Vitest)
pnpm --filter @aire/client test

# 2. Run real-browser UX4G check across 7 viewports (Chromium / Playwright)
pnpm run test:ux4g

# 3. Run full local CI pipeline
pnpm run ci
```
