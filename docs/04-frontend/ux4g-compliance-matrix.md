## 1. Compliance Matrix Overview

This matrix maps AIRE's frontend implementation against the parameters and heuristic guidelines established in the **UX4G User Experience Handbook** (Ministry of Electronics and Information Technology / NeGD).

Status Definitions:

- **PASS:** Fully implemented and verified in code and tests.
- **PARTIAL:** Implemented with specific approved constraints or conditional scope.
- **NOT APPLICABLE (N/A):** Outside statutory product boundaries with documented justification.
- **OPEN:** Pending upstream statutory decision or external credential provisioning.
