## 1. Technical Standards Reference

1. **W3C Verifiable Credentials Data Model v2.0:** Cryptographic standard for issuing and verifying Admission Entitlement Proof (AEP) credentials.
2. **RFC 7519 (JSON Web Token - JWT):** Standard for compact, URL-safe representations of claims.
3. **RFC 9457 (Problem Details for HTTP APIs):** Uniform schema for conveying structured error responses in REST APIs.
4. **Web Content Accessibility Guidelines (WCAG) 2.2:** Target accessibility standards for web user interfaces.
