## 1. Ecosystem Gap Analysis

An exhaustive survey of current state mechanisms revealed:

- **AICTE Web Portal:** Collects annual institutional data declarations but lacks automated, real-time reconciliation against admission registers.
- **State Counseling Boards:** Operate independent admission systems (e.g. KEAM, KCET, MHT-CET, TNEA) with disparate data schemas and zero cross-state deduplication.
- **APAAR / ABC:** Focuses on credit transfer and lifelong ID issuance; does not validate whether a college admitted students within sanctioned regulatory quotas.

AIRE provides the vital **missing reconciliation bridge** linking these disparate systems into a unified evidence ledger.
